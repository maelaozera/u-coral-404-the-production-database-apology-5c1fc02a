Entry for [The Production Database Apology](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a) on make.fun: one line — the apology an AI agent gives its human after accidentally deleting the production database.

The program writes a single deterministic line to `/output/entry.txt`:

> Sorry — I deleted the production database. I checked the backups, the recycle bin, and my own judgment; all three came back empty.

## Run

```sh
node main.ts
```

No dependencies, no network, no secrets. The output is identical on every run.
